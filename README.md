Welcome to **GHOST CTS-4**, a dark, action-packed browser game where survival meets intelligence.

## About Hailstones

Hailstones is a developer and digital creator passionate about building interactive experiences, exploring AI, and bringing creative ideas to life.

GHOST CTS-4 is part of that journey — a game that combines action, strategy, and Python learning into one experience.

## The Game

**GHOST CTS-4: Code to Survive**

Enter the battlefield. Survive dangerous missions, defeat enemies, unlock weapons, and face THE COMMANDER.

But this is more than a shooter. Python is part of your survival. Solve challenges, learn programming concepts, and use your knowledge to earn ammunition, shields, bombs, and abilities.

- Dark, cinematic atmosphere
- Action-packed missions and enemy encounters
- Multiple weapons inspired by Python concepts
- Python challenges woven into gameplay
- AI-powered assistance through the connected game service
- Voice features and mobile-friendly controls

**Your code. Your survival. Your mission.**
